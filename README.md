# Aicd

This is a fork of https://github.com/mganss/Aicd which is brilliant of an acid pattern MIDI generator Max for Live device based on a maximum likelihood n-gram model.


## Features

- Generate variable length patterns (1-64 steps)
- Save generated patterns as presets
- Influence randomness through temperature dial
- Choose velocity of unaccented steps (default 99, accented steps are always 127)
- Fold/zoom sequencer view
- View/edit pitch, velocity, slide, gate independently
- Create clip
- Set permanently updated output clip

## Usage

Drag device into a MIDI track and hit the acid smiley button. Generated patterns enter Live's undo history. 
If you like a pattern, <kbd>Shift-click</kbd> one of the preset boxes to save it as a preset.

### Default pitch

The untransposed C (no up/down) note is generated as MIDI note 36 (called C1 in Ableton, generating 32.7Hz). 
This is also what ABL3 and Phoscyon generate. For some other synths, you'll have to transpose an octave up.

## Model

The model was generated by training on a large number of patterns in ABL3 format (not in this repo) 
using the approach described by Joav Goldberg [here](http://nbviewer.jupyter.org/gist/yoavg/d76121dfde2618422139).

To generate a model, you need only Node.js:

```
node train.js <folder-with-.pat-files> --order 18 --out lm.js
```

This reads all `.pat` files below the folder, writes the condensed training text (optionally with `--text-out input_patterns.txt`) and the model `lm.js`. 
To retrain from an existing `input_patterns.txt`, use `--text input_patterns.txt`. 
`patterns.csx` and `model.csx` are the original C# scripts and are no longer needed.

## Transpose, scale, mutate

- **Transpose** shifts the clip and the playback by up to 24 semitones.
- **Root** and **Scale** move the notes into a scale (the lower note if two are equally near). The scale is applied after Transpose, so the root is the absolute key of the output. Off leaves the notes as generated. 
- **Mutate** replaces **Amount** percent of the steps with new ones and keeps the rest.

Changing Root or Scale also moves the steps in the step editor into the scale, and newly generated or mutated steps are put into it. This overwrites the editor's pitches, so switching Scale back to Off does not restore them (Generate or Mutate again for new ones). Transpose only changes what is played and written to the clip, not the editor.

## Density

**Rests** is the percentage of the steps that are rests, **Slides** and **Accents** the percentage of the notes that slide or are accented. The editor always shows exactly these numbers (rounded to whole steps); at 100% every step is a rest. The starting values (10 / 33 / 33) are roughly what the model generates on average; the model's own rests, slides and accents are not used.

The controls act on the pattern in the editor and on newly generated patterns. Moving a control adds or removes the same steps in the same order, so it is consistent and reversible. Only steps whose rest, slide or accent actually changes are touched, so other manual edits stay. A drag of the controls is one Undo step. Mutate gives the chosen steps new pitches and shuffles their rest / slide / accent pattern among themselves, which keeps the percentages exact. If you change the pattern length after generating, the next density change (or Mutate) makes the whole new length match the percentages: new steps get their own rests, slides and accents, and the percentages are taken of the new length. Patterns that were not generated in the current session (e.g. a loaded Live set) are left alone until you Generate. The results are reproducible with a Seed.

## Seed

**Seed** 0 gives a new random pattern every time. Any other number (up to 999999) gives the same pattern for the same settings, every time. **Last seed** shows the seed of the last generated pattern; type it into Seed to get that pattern again. Mutate ignores the Seed setting, as it would otherwise repeat the same change every time.

## History

**Undo** and **Redo** step through the last 50 states of the step editor before each Generate, Mutate or scale change. Manual edits are part of the state when the next change happens. Undo does not move the Scale, Root or Transpose controls.

## Temperature

Temperature runs from 0.3 (close to the trained patterns) to 5 (very random).

## Tests

`node --test` runs the sampler and trainer tests outside of Max.

## Building the device

`Aicd.amxd` is frozen, i.e. it contains its own copy of `acid.js`, `lm.js` etc. After changing `acid.js` or the patch (`Aicd.maxpat`), pack the device again:

```
python3 tools/amxd.py build Aicd.maxpat Aicd.amxd
```

`python3 tools/amxd.py extract Aicd.amxd Aicd.maxpat` extracts the patch from a device saved in Max.
